# Oceanic Expanse Wiki

Documentation for **Oceanic Expanse**, a Minecraft 1.12.2 mod that adds new content and expands upon Minecraft's oceans.

Pages live in `docs/`, one folder per sidebar category (`mobs`, `blocks`, `items`, ...). Each folder's `_category_.json` sets its label and order.

## Local Development

The wiki is built using [Docusaurus](https://docusaurus.io/). To run it locally:

```bash
npm install
npm start
```

## Build

```bash
npm run build
```

This generates static content into the `build` directory, which can be served by any static hosting service.
