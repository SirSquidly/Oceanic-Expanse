Shell Patches are features of [shelly sand](../blocks/shelly-sand.md) and rarely [sea stars](../blocks/sea-star.md) that generates on beaches.

## Generation
Shell Patches generate on beaches, on sand blocks at or less than _2 blocks_⁽¹⁾ above sea level.

Shelly sand in shell patches will never generate more than 1 block deep, keeping it very shallow. When the block directly above the shelly sand is air, there is a _1/20_⁽¹⁾ chance to place a sea star atop.

## Blocks and Items
Items obtained from Shell Patches:
* [Shelly sand](../blocks/shelly-sand.md) (harvested with Silk Touch)
* [Sea Star](../blocks/sea-star.md) (harvested by hand)


1. ↑ Features are configurable.
