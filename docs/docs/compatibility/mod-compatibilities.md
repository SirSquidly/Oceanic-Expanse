---
title: "Mod Compatibilities"
---

Compatibility between mods becomes complicated very fast, as varying standards and expertise in projects may result in unique interactions, intentional or not. That is to say sometimes Oceanic Expanse is built to work with something, or sometimes it catches on fire (not literally).


| Mod Name                  | Compatibility         | Notes                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| ------------------------- | --------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Aqua Acrobatics           | Compatable            | When installed, the [the Descent effect is intensified to require fast swimming](../effects/descent.md#aqua-acrobatics).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| Enchantment Descriptions  | Compatable            | Descriptions are added for [Channeling](../enchantments/channeling.md#enchantment-descriptions), [Impaling](../enchantments/impaling.md#enchantment-descriptions), [Loyalty](../enchantments/loyalty.md#enchantment-descriptions), [Riptide](../enchantments/riptide.md#enchantment-descriptions), and [Waterjet](../enchantments/waterjet.md#enchantment-descriptions).                                                                                                                                                                                                                                                                                                                                                       |
| Fluidlogged API           | Compatable            | Oceanic Expanse blocks are automatically fluidloggable, and worldgen is altered to allow surface plants. **This only functions in a freshly generated world, this is just how Fluidlogged works**.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| Just Enough Items (JEI)   | Compatable            | Detailed Information is added for [Barnacle Shells](../items/barnacle-shells.md#just-enough-items-jei), [Coconuts](../blocks/coconut.md#just-enough-items-jei), [Conduits](../blocks/conduit.md#just-enough-items-jei), [Guardian Spikes](../blocks/guardian-spike.md#just-enough-items-jei), [Flowering Palm Leaves](../blocks/flowering-coconut-leaves.md#just-enough-items-jei), [Sea Oats](../blocks/sea-oats.md#just-enough-items-jei), [Sea Pickles](../blocks/sea-pickle.md#just-enough-items-jei), and [Shelly Sand](../blocks/shelly-sand.md#just-enough-items-jei). |
| Potion Descriptions       | Compatable            | Descriptions are added for [Descent](../effects/descent.md#potion-descriptions) and [Conduit Power](../effects/conduit-power.md#potion-descriptions).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| Project: Vibrant Journeys | Incompatible          | The included Starfish Mob from Project: Vibrant Journeys fills the spawn cap near the oceans, leading to most mobs from Oceanic Expanse failing to spawn. Setting `starfishWeight` to 0 will disable Starfish spawning, allowing normal Oceanic Expanse mobs to spawn.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| RandomTweaks              | Major Incompatibility | RandomTweaks alters squid spawning in ways that lead to excessive Drowned spawns. This cannot be fixed on Oceanic Expanse's end.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| RLTweaks                  | Incompatible          | Injected AI is incompatible with Drowned, and needs to be disabled in the config, set `allZombiesBreakDoors` to false. <br><br>If this config is not altered, the injected AI will be automatically removed, and will give warnings in the logs. In versions below 1.1.0, the injected AI causes a crash.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| Special AI                | Incompatible          | Certain behavior such as Undead having swimming removed does not function when SpecialAI is installed, and it is necessary to alter the SpecialAI config, adding `oe:drowned 0.0 oe:pickled 0.0` to the `door_breaking` `mob_list` in the config. <br><br>If this config is not altered, the injected AI will be automatically removed, and will give warnings in the logs. In versions below 1.1.0, the injected AI causes a crash.                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| Trident                   | Major Incompatibility | Hard crash due to Trident trying to hook into Oceanic Expanse's Trident using Mixins. Versions below 1.1.0 are fully compatible.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| VanillaFix                | Major Incompatibility | Hard crash when starting game, VanillaFix has major incompatibilities with various mods utilizing Mixins.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
