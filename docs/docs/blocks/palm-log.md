Palm Logs are blocks that spawn as part of [palm trees](../generation/palm-tree.md), and are used to craft [Palm Planks](../blocks/palm-planks.md).

Stripped Palm Logs can be made by using an Axe on a Palm Log. This cannot be reversed.

## Obtaining
### Breaking
Palm Woods can be mined by hand, but an axe speeds up the process.

### Post-generation
Palm Logs spawn as part of [palm trees](../generation/palm-tree.md) when grown from [Palm Saplings](../blocks/palm-sapling.md).

## Usage
### Crafting Ingredient
Palm Logs can be crafted into [Palm Wood](../blocks/palm-wood.md) or Palm Planks.
Stripped Palm Logs can be crafted into [Stripped Palm Wood](../blocks/palm-wood.md) or Palm Planks.
