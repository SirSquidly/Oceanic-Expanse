Sea stars is a non-solid stationary marine animals.

## Obtaining
### Breaking
Sea stars can be mined by hand.

### Natural Generation
**Frozen Oceans**  
Sea stars generate in [frozen oceans](../generation/frozen-ocean.md), in patches on the seafloor.  

**Shell Patches**  
In [shell patches](../generation/shell-patches.md), when [shelly sand](../blocks/shelly-sand.md) generates with air above it, there is a 1/20⁽¹⁾ chance a starfish is placed atop.

## Usage
Sea stars can be placed underwater, atop any solid block.
