Palm Wood is a block with [Palm Log](../blocks/palm-log.md)'s bark texture on every side.

Stripped Palm Wood can be made by using an Axe on a Palm Wood. This cannot be reversed.

## Obtaining
### Breaking
Palm Wood can be mined by hand, but an axe speeds up the process.

## Usage
### Crafting Ingredient
Palm Wood and Stripped Palm Wood can be crafted into [Palm Planks](../blocks/palm-planks.md).
