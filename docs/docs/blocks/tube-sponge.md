Tube sponge is a non-solid sponge block.

## Obtaining
### Breaking
Tube sponge can only be obtained using Shears or Silk Touch enchanted tools. If mined without, nothing is dropped.

### Natural Generation
Tube sponge generates in [frozen oceans](../generation/frozen-ocean.md), in patches on the seafloor.

## Usage
Tube sponge can be placed underwater, atop any solid block.

### Growth Mechanics
<img align="right" img src='https://i.imgur.com/VHZ4BaY.png' width='300'>
Tube sponge has 3 stages of growth, each visually distinct. It grows extremely slowly, but the growth speed can be increased by planting it atop a wet sponge block.
