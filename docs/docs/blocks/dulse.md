Dulse is a seaweed that can be planted underwater, or cooked to make [dried dulse](../items/dried-dulse.md).

## Obtaining
### Breaking
Dulse can be mined by hand. Each growth stage of Dulse adds an additional piece when mined. 

### Natural Generation
Dulse generates in [frozen oceans](../generation/frozen-ocean.md), in patches on the seafloor.

## Usage
Dulse can be placed underwater, atop any solid block.

### Growth Mechanics
Dulse has 4 stages of growth, each visually distinct. To reach the 4th stage, the block above must also be water.
Bone meal can be used on Dulse.

Using Shears on Dulse will lock it to it's current age.

### Smelting Ingredient
Dulse can be smelted to cook [dried dulse](../items/dried-dulse.md).
