A Prismarine Pot is a block used to store items, and can be plugged to prevent being opened.

## Obtaining

### Breaking
Prismarine Pots can only be obtained using Pickaxes enchanted with Silk Touch. If mined without, it drops 3 (+ Fortune Level) to 7 Prismarine Shards. Any contained items are also dropped.

### Crafting
Prismarine Pots can be crafted using a Pearl and 7 Prismarine Shards.

### Natural Generation
Prismarine Pots generate in ocean monuments, most prominently within the structure.

## Usage
<img align="right" img src='https://i.imgur.com/y4aC4Ws.png' width='230'>

### Container
Prismarine Pots have a container inventory of 4 slots. This can be accessed by interacting with it.

The interface of the prismarine pot is labeled "Prismarine Pot". This label cannot be changed.

### Plugging
Using a Wood Button on a prismarine pot plugs it, disallowing it from being opened. This also increases the hardness of the pot, making it harder to mine. There is no way to remove the plug in Survial, without breaking the block.

In Creative Mode, using an Axe removes the plug.
