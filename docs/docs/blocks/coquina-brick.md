Coquina Brick is a decorative block crafted from 4 [Coquina](../blocks/coquina.md). It can be made into Slabs, Stairs, and Walls.

## Obtaining
### Breaking
Coquina Brick requires a pickaxe to be picked up.

### Crafting
Coquina Brick can be crafted from 4 Coquina.

## Usage
Coquina Brick has a blast resistance of 9, putting it at the same amount as End stone.

### Crafting Ingredient
Coquina Brick can be crafted into Slabs, Stairs, and Walls.
