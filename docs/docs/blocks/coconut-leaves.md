---
title: "Coconut Leaves"
---

Coconut leaves are blocks that spawn as part of [palm trees](../generation/palm-tree.md).
## Obtaining
### Breaking
Coconut leaves can only be obtained using Shears or Silk Touch enchanted tools. If mined without, nothing is dropped.

### Post-generation
Coconut leaves spawn as part of [palm trees](../generation/palm-tree.md) when grown from [palm saplings](../blocks/palm-sapling.md).

## Usage
Coconut leaves have the [same functionality as normal leaves](https://minecraft.fandom.com/wiki/Leaves#Usage).
