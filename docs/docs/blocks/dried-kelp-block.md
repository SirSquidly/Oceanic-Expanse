Dried kelp blocks are storage blocks made of 9 [dried kelp](../items/dried-kelp.md), and can be used as fuel.

## Obtaining
### Breaking
Dried kelp blocks can be mined quickly by hand or any tool. Although, if the string on the block has been removed with shears, it will instead drop 9 dried kelp, which are equal how the amount used to craft the block.

### Crafting
Crafting together 9 [dried kelp](../items/dried-kelp.md) produces a dried kelp block.

## Usage
Dried kelp blocks can be used for storing or condensing dried kelp.

### Fuel
Dried kelp blocks can be used as fuel in a furnace, or any furnace derivatives. Its burning time is 200 seconds (4000 ticks), making able to smelt 20 items.

### Crafting Ingredient
Crafting a dried kelp block will return the 9 [dried kelp](../items/dried-kelp.md) it is made from.

### Snipping
Right-Clicking a dried kelp block with shears removes the string from it. This is only for decoration purposes, although a stringless dried kelp block will drop 9 dried kelp rather than itself.
