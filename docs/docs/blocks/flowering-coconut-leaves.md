title: "Flowering Coconut Leaves"
---

Flowering coconut leaves are non-harvestable block that spawn as part of [palm trees](../generation/palm-tree.md), and grows [coconuts](../blocks/coconut.md).

## Obtaining
Flowering coconut leaves can be obtained using the creative menu or commands, but otherwise cannot be obtained in survival mode.

### Breaking
Flowering coconut leaves cannot be obtained when mined, even using shears or a Silk Touch enchanted tool.

### Post-generation
Flowering coconut leaves spawn as part of [coconut trees](../generation/palm-tree.md) around the top log, when grown from Coconut Saplings.

## Usage
Each random tick, there is a 20% chance of spawning a [coconut](../blocks/coconut.md) below it, as long as the space below is only occupied by air. Bonemeal can be used to imminently run this chance. 


## Mod Compatibility
_Main page: [Mod Compatibilities](../compatibility/mod-compatibilities.md)_
