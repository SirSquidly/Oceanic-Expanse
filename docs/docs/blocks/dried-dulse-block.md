Dried dulse blocks are storage blocks made of 9 [dried dulse](../items/dried-dulse.md), and can be used as fuel.

## Obtaining
### Breaking
Dried dulse blocks can be mined quickly by hand or any tool. Although, if the string on the block has been removed with shears, it will instead drop 9 dried dulse, which are equal how the amount used to craft the block.

### Crafting
Crafting together 9 [dried dulse](../items/dried-dulse.md) produces a dried dulse block.

## Usage
Dried dulse blocks can be used for storing or condensing dried dulse.

### Fuel
Dried dulse blocks can be used as fuel in a furnace, or any furnace derivatives. Its burning time is 200 seconds (4000 ticks), making able to smelt 20 items.

### Crafting Ingredient
Crafting a dried dulse block will return the 9 [dried dulse](../items/dried-dulse.md) it is made from.

### Snipping
Right-Clicking a dried dulse block with shears removes the string from it. This is only for decoration purposes, although a stringless dried dulse block will drop 9 dried dulse rather than itself.
