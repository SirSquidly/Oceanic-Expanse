Shelly Sand is a block that is found in [shell patches](../generation/shell-patches.md) on beaches. Using or breaking it with a shovel gives specific items.

## Obtaining

### Breaking
Shelly Sand can only be obtained using Silk Touch enchanted tools. If mined without, it is replaced with sand and spawns its loot.

### Natural Generation
Shelly sand generates in [shell patches](../generation/shell-patches.md) on beaches, and is more likely to generate when exposed to air.

## Usage

### Loot
Using or breaking Shelly Sand with a shovel will spawn and item, and convert the Shelly Sand into regular sand.
