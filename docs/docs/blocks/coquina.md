Coquina is a block of soft limestone, found in [coquina outcrops](../generation/coquina-outcrop.md) on beaches.

## Obtaining
### Breaking
Coquina requires a pickaxe to be picked up.

### Natural generation
Coquina spawns in [coquina outcrops](../generation/coquina-outcrop.md) on beaches.

### Crafting
Coquina can be crafted from [barnacle shells](../items/barnacle-shells.md) and Bonemeal.

## Usage
Coquina has a blast resistance of 9, putting it at the same amount as End stone.

### Crafting Ingredient
Coquina can be crafted [Coquina Brick](../blocks/coquina-brick.md).
