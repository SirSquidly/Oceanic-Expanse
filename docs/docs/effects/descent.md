---
title: "Descent"
---

Descent is a status effect that pulls an entity down.

## Effect
Descent pulls the affected entity down in two circumstances:

### Falling
When the affected entity is falling, it will be pulled down, increasing and multiplying it's fall rate. This rate increases by the currently speed, making it build speed exponentially.

### In Water
When the affected entity is in Water, they are pulled down in the same manner as falling. This behavior is altered if Aqua Acrobatics is installed.

## Mod Compatability
_Main page: [Mod Compatibilities](../compatibility/mod-compatibilities.md)_  

### Aqua Acrobatics
If the mod Aqua Acrobatics is installed, the pull when submerged in water is more intense, requiring the player to Sprint-Swim in order to elevate themselves.

### Potion Descriptions
The following description is attached to Descent when Potion Descriptions is installed:  
`Pulls affected entities downward.`
