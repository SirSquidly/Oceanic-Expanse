## Bucketting
Using a Bucket or Bucket of Water on an _applicable mob_⁽¹⁾ lets you obtain it in a [spawn bucket](../items/spawn-bucket.md). 

If the mob is named, the bucket adopts the name of the mob as "Bucket of [Name]".

#### Buckettable Mobs
_Certain mobs_⁽¹⁾ can be bucketted. These include:

| Buckettable mobs |
| -------- |
| Baby Squid |
| Baby Glow Squid |
| Cod |
| Salmon |
| Pufferfish |
| Tropical Fish |
| Crab |

***

1. ↑ Given list of buckettable mobs is the default defined in the config. The config can be altered, adding or removing almost any mob.

## Squid Flopping
Outside of water, in the same way Fish do, Squids will begin flopping about trying to get back into water. The rate of their flopping increases when they run out of air and begin suffocating.

## Squid Inking
When a Squid is attacked, it will spawn a cloud of ink particles. This cloud comes out of the bottom of the squid, at the mouth. Any entity within the cloud is given Blindness for _5_⁽¹⁾ seconds.

Baby Squids produce _less_ ink, and cannot cause blindness.

Glow Squids (and Glow Squid Babies) have a custom colored ink.

## Squid Pushing
Using an empty hand on a Squid outside of water allows the player to give it a push. This is so Players can actually help said squids, as physically walking it it doesn't... work. Weird Vanilla Bug.

## Underwater Bone Mealing
Using Bone Meal underwater places Seagrass within an 8x8 area, along with extending Seagrass into Tall Seagrass.

If a block within the area is _beside or atop a Coral Block_⁽¹⁾, there's a _1/5 chance_⁽¹⁾ to instead place a random Coral Fan or Coral at the spot.


1. ↑ Features are configurable.
