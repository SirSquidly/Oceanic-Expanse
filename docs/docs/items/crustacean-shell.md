A Crustacean Shell is an item primarily obtained from [Lobsters](../mobs/lobster.md) and other custaceans. It is used in various recipes

## Obtaining
### Mob Drops
#### Crabs
Each Adult [Crab](../mobs/crab.md) has a 10% chance to drop a crustacean shell when killed. This chance increases by 1% per level of Looting.

#### Lobsters
Adult [Lobsters](../mobs/lobster.md) drop 0-1 crustacean shell when killed. This amount increases depending on the lobster's size, being size / 3, rounded down. Along with this, each level of Looting adds 0-1 more rolls.

For example, a size 10 lobster killed with Looting 3 will drop 0-6 Crustacean Shell.

### Molting
Lobsters will drop 1 crustacean shell every time they [molt](../mobs/lobster.md#molting).

## Usage
### Crafting
4 Crustacean shells can be used to craft Bonemeal.

2 Crustacean Shells and 2 Bonemeal can be used to craft [Coquina](../blocks/coquina.md).

A Crustacean Shell, a [Cooked Crab](../items/cooked-crab.md), a Milk Bucket, and a Bowl can be used to craft [Crab Bisque](../items/crab-bisque.md).

A Crustacean Shell, a [Cooked Lobster](../items/cooked-lobster.md), a Milk Bucket, and a Bowl can be used to craft [Lobster Bisque](../items/lobster-bisque.md).

### Lobsters
Crustacean Shells can be used to lead [Lobsters](../mobs/lobster.md), and can be given to or collected by Lobsters to [eat](../mobs/lobster.md#eating).
