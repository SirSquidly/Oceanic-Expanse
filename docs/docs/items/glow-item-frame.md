A Glow Item frame is a glowing variant of an [item frame](https://minecraft.wiki/w/Item_Frame), which illuminates itself and held items.

## Obtaining
Hitting a glow item frame will make it drop as an item. If it is holding an item, it will instead drop the held item.

### Crafting
Glow Item Frames can be crafted using an Item Frame and [Glow Ink Sac](../items/glow-ink-sac.md).

## Usage
Glow Item Frames share most of the same uses, properties, and rotation as vanilla item frames.

### Differences
Glow Item Frames have a minimum light level, thus appear to glow. Any held items are rendered in full bright.

_They can also be placed on ceilings and floors, a function later added to vanilla item frames in 1.13._⁽¹⁾
