A Spawn Bucket (In-game named "Bucket of [Mob Name]") is a bucket of water with a mob inside. 

## Obtaining
_Main page: [Bucketting](../mechanics/mechanics.md#bucketting)_

Using a Bucket or Bucket of Water on an _[applicable mobs](../mechanics/mechanics.md#buckettable-mobs)_ lets you obtain it in a Spawn Bucket.

## Usage
Using the bucket places a water source block, along with the contained mob, leaving an empty bucket in the player's inventory. Attributes of the original bucketted entity are kept, including custom names and health. If a spawn bucket is used in the Nether, like a normal bucket of water, the water will instead be evaporated as smoke, and the entity will be placed alone.

Renaming a bucket in an anvil will apply the custom name to the mob when placed.

### Naming
If a bucketted entity has a custom name, the name will be reflected in the bucket name as "Bucket of [Name]".

_Main page: [Tropical Fish Names](../mobs/tropical-fish.md#names)_

Tropical Fish utilize assigned names when bucketted, reflected both in _the bucket name_⁽¹⁾ and in _a tooltip_⁽¹⁾.
