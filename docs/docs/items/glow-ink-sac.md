A glow ink sac is an item dropped by a [glow squid](../mobs/glow-squid.md) on death.

## Obtaining
### Mob Drops
Glow  Squids drop 0-2 glow ink sacs upon death. The maximum is increased by 1 per each level of Looting.

## Usage
### Crafting
Glow ink sacs can be used to craft [underwater torches](../blocks/underwater-torch.md).
