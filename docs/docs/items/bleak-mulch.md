Bleak Mulch is a material used to remove Seagrass.

## Obtaining
### Crafting
Bleak Mulch can be crafted using a Pearl and a Prismarine Shard.

## Usage
Using Bleak Mulch on a block removes all Seagrass in a an _15x15x15_⁽¹⁾ area. Removed Seagrass is replaced by Water.
