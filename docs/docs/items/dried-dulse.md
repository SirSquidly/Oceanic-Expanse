Dried Dulse is a food item. It can be crafted into [dried dulse blocks](../blocks/dried-dulse-block.md).

## Obtaining
### Smelting
[Dulse](../blocks/dulse.md) can be cooked in a furnace to create dried dulse, and creates 0.1 experience.

### Crafting
A dried dulse block can be uncrafted into dried dulse

## Usage
### Food
Dried dulse restores 3 hunger and 3.6 saturation, making it equal to a carrot.

### Crafting Ingredient
9 dried dulse can be crafted into a dried dulse block.
