## Potion of Descent
The potion of Descent gives the Descent status effect for 2 minutes when used. It cannot be enhanced or extended.

#### Obtaining
Potions of Descent are brewed using [barnacle shells](../items/barnacle-shells.md) and an awkward potion.

#### Length
| Type      | Length |
| --------- | ------ |
| Normal    | 2:00   |
| Splash    | 2:00   |
| Arrow     | 0:15   |
| Lingering | 0:30   |

### History
| Version | Changes |
| ------- | ------- |
| [1.0.7](../versions/version-1-0-7.md) | Potions of Descent can now be brewed from an Awkward Potion and Barnacle Shells. |

## Potion of the Turtle Master
The potion of the Turtle Master gives the Resistance and Slowness status effects at level 3 for 20 seconds when used. When enhanced with glowstone dust, the status effects are upgraded to level 5. When extended with redstone dust, the status effect lengths are doubled.

#### Obtaining
Potions of the Turtle Master are brewed using a [turtle shell](../items/turtle-shell.md) and an awkward potion.

#### Length
Base and enhanced lenths:
| Type      | Length |
| --------- | ------ |
| Normal    | 0:20   |
| Splash    | 0:20   |
| Arrow     | 0:02   |
| Lingering | 0:05   |

Extended lenths:
| Type      | Length |
| --------- | ------ |
| Normal    | 0:40   |
| Splash    | 0:40   |
| Arrow     | 0:05   |
| Lingering | 0:10   |
