A scute is an item dropped by baby [turtles](../mobs/turtle.md) when they grow into adults. It is used to craft and repair [turtle shells](../items/turtle-shell.md).

## Obtaining
### Mob Loot
A scute is dropped when a baby [turtle](../mobs/turtle.md) grows into an adult.

## Usage
### Crafting
5 scute can be used to craft a [turtle shell](../items/turtle-shell.md).

### Repairing
Scutes can be used in an anvil to repair a turtle shell, restoring 25% of the total durability while preserving the enchantments.
