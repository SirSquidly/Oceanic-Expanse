Chlorine is a creative mode tool used for removing Seagrass.

## Obtaining
Chlorine can be obtained using the creative inventory or commands, but otherwise cannot be obtained in survival mode.

## Usage
Right-Clicking any block while holding Chlorine will remove all Seagrass and Tall Seagrass in an 8x8x8 cube, replacing them with water.
