Riptide is a [trident](../items/trident.md) enchantment that launches the user in the direction they are facing, when wet.

## Usage
Riptide tridents can only be used when a player stands in water or when exposed to rain. When used, rather than throwing the trident, a the player is launched. Players can reach greater heights by throwing a Riptide trident straight upward, and travel further distances by throwing it from a higher altitude.

The formula for the number of blocks the trident throws the user is (6.5 × level) + 2.

If the player use riptide near a mob or another player, the trident deals throwing damage. Using riptide costs 1 durability, with an addition 1 durability per mob damaged. This damage bypasses shields.

## Incompatibilities
Riptide is mutually exclusive with Loyalty and [Channeling](../enchantments/channeling.md).

## Mod Compatibility
_Main page: [Mod Compatibilities](../compatibility/mod-compatibilities.md)_  
### Enchantment Descriptions
The following description is attached to Riptide when Enchantment Descriptions is installed:  
`Launches the owner in the direction they are facing, if they are wet.`
