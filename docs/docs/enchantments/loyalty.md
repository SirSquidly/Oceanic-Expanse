---
title: "Loyalty"
---

Loyalty is a [trident](../items/trident.md) enchantment that causes the trident to return to the owner when thrown.

## Usage
Loyalty tridents will, upon impacting a mob or block, fly back to the owner. The speed of its return scales with the level of Loyalty. 

Returning Tridents will not deal damage to mobs, and can pass through blocks. _A Loyalty Trident thrown into the void will return_⁽¹⁾ when it reaches _Y=-15_⁽¹⁾.

## Incompatibilities
Loyalty is mutually exclusive with [Riptide](../enchantments/riptide.md).

## Mod Compatibility
_Main page: [Mod Compatibilities](../compatibility/mod-compatibilities.md)_  
### Enchantment Descriptions
The following description is attached to Loyalty when Enchantment Descriptions is installed:  
`Returns to the owner upon impacting a mob or block.`
