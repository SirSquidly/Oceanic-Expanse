Impaling is a [trident](../items/trident.md) enchantment that increases damage dealt to aquatic mobs.

## Usage
Each level of Impaling adds _2.5_⁽¹⁾ extra damage per hit.

Impaling is only applied when dealing to _aquatic mobs_⁽¹⁾, which by default includes [cod](../mobs/cod.md), [crabs](../mobs/crab.md), [drowned](../mobs/drowned.md), elder guardians, glow squids, guardians, [pickled](../mobs/pickled.md), pufferfish, [salmon](../mobs/salmon.md), squids, and [turtles](../mobs/turtle.md).

## Incompatibilities
Impaling and [Waterjet](../enchantments/waterjet.md) are mutually exclusive, and cannot be combined.

## Mod Compatibility
_Main page: [Mod Compatibilities](../compatibility/mod-compatibilities.md)_  
### Enchantment Descriptions
The following description is attached to Impaling when Enchantment Descriptions is installed:  
`Increases the damage dealt to aquatic mobs.`
