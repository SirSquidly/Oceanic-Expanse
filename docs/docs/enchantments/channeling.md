Channeling is a [trident](../items/trident.md) enchantment that strikes lightning.

## Usage
Channeling summons a lightning bolt when a mob is hit by a thrown trident, if a [thunderstorm](https://minecraft.fandom.com/wiki/Thunderstorm) is currently occurring. The mob needs to be exposed to the sky for lighting to strike.

In other circumstances, Channeling will not strike a mob. These include:
if the mob is _in Lava_⁽¹⁾,
if the mob is _in Water_⁽¹⁾,
or if the mob is riding a _Boat or Minecart_⁽¹⁾.

Channeling tridents thrown at _Iron Bars_⁽¹⁾ always create lightning without the need for a mob.

## Incompatibilities
Channeling and [Riptide](../enchantments/riptide.md) are mutually exclusive, and cannot be combined.

## Mod Compatibility
_Main page: [Mod Compatibilities](../compatibility/mod-compatibilities.md)_  
### Enchantment Descriptions
The following description is attached to Channeling when Enchantment Descriptions is installed:  
`Strikes lightning when impacting a mob or lightning rod during a thunderstorm.`
