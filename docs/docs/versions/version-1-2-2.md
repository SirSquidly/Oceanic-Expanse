1.2.2 is a minor bug fix update for Oceanic Expanse, released on September 18, 2025, adding multiple new languages and multiple server bug fixes.

## Additions

### Languages
* Added Russian, contributed by K-LAgama

## Changes

### Blocks

#### [Palm Sapling](../blocks/palm-sapling.md)
* Will naturally grow into full Palm Trees

#### [Shelly Sand](../blocks/shelly-sand.md)
* Allows Sugar Cane (if bordering water) and Desert Plants atop

### Items

#### [Trident](../items/trident.md)
* No longer saves original Owner, if they were not a Player

### Languages
* Updated Simplified Chinese, contributed by SaltOvOFish


### World generation

#### [Frozen Ocean](../generation/frozen-ocean.md)
* Lowered spawn rate to match pre-1.2.0 versions


## Bugfixes
4 issues fixed

* Fixed Shelly Sand not allowing Sugar Cane or desert plants atop
* Fixed Shelly Sand particles being client-side only
* Fixed Tridents improperly saving non-player entities (submitted by Nischhelm)
* Fixed Dolphin Spawns registering when Dolphins are disabled
